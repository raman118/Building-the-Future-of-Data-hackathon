# Fashion Retail Intelligence System - BigQuery AI Hackathon 2025

This project is a submission for the [BigQuery AI Hackathon 2025](https://www.kaggle.com/competitions/bigquery-ai-hackathon) on Kaggle. It's an advanced geospatial intelligence system for global fashion retail analysis using BigQuery ML and AI-powered clustering algorithms.

## Project Overview & Objectives

This project was developed for the **BigQuery AI Hackathon 2025**, focusing on advanced geospatial analytics and machine learning applications. The primary objective is to develop an advanced geospatial intelligence system for global fashion retail analysis using BigQuery ML and AI-powered clustering algorithms.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

*   Python 3.x
*   Jupyter Notebook or JupyterLab
*   Google Cloud SDK (for BigQuery integration)

### Installing

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd <repository-folder>
    ```

2.  **Create a virtual environment:**
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # On Windows use `.venv\Scripts\activate`
    ```

3.  **Install the required packages:**
    It is recommended to check the imports in the `fashion-retail-intelligence-bigquery-ai-hackatho.ipynb` notebook for the full list of dependencies. A good starting point would be:
    ```bash
    pip install pandas numpy matplotlib seaborn jupyterlab google-cloud-bigquery
    ```

## Usage

To run the project, start JupyterLab or Jupyter Notebook:

```bash
jupyter lab
```

Then, open the `fashion-retail-intelligence-bigquery-ai-hackatho.ipynb` notebook and execute the cells.

## Project Structure

*   `fashion-retail-intelligence-bigquery-ai-hackatho.ipynb`: The main Jupyter notebook containing the entire analysis, from data extraction to machine learning insights and visualizations.
